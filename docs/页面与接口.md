# 页面与接口

所有登录后的业务接口位于 `/api/v1`。网页使用同站 HTTP-only 会话 Cookie；微信小程序用 `x-client: wechat-mini` 登录后取得 12 小时有效的 Bearer 凭证，后续请求放在 `Authorization` 头。写操作使用 JSON；建议请求头携带唯一 `Idempotency-Key`。成功返回业务对象，失败返回 `{ "error": "中文说明" }` 与相应 HTTP 状态。数据库金额以分保存，接口金额传输为十进制元字符串。服务端执行角色、权限、指定客户及 `merchantId` 校验。老板在员工权限中多选可访问客户；未分配客户的员工无法查询或处理该客户档案和业务单据。

| 模块 | 主要接口 |
|---|---|
| 登录 | `POST /login`、`POST /logout`、`GET /me` |
| 首页 | `GET /dashboard` |
| 合作方 | `GET/POST /partners`、`GET /partners/:id`、`POST /partners/:id/update` |
| 货品 | `GET/POST /goods`、`GET /goods/:id`、`POST /goods/:id/update`、`/move`、`/reserve`、`/unreserve`、`/return-upstream` |
| 拿货 | `GET/POST /loans`、`POST /loan-items/:id/return`、`/transfer` |
| 销售 | `GET/POST /sales`、`POST /sale-items/:id/deliver`、`/return`、`POST /sales/:id/fees` |
| 资金 | `GET/POST /receipts`、`POST /receipts/:id/allocate`、`/allocate-opening`、`/apply`、`/refund`、`GET /payables`、`POST /payments`、`GET /money-entries` |
| 盘点 | `GET/POST /stocktakes`、`POST /stocktakes/:id/scan`、`POST /stocktake-findings/:id/resolve`、`POST /stocktakes/:id/close` |
| 异常货 | `GET /damages`、`POST /damages/:id/review` |
| 管理 | `GET/POST /users`、`POST /users/:id/permissions`、`GET/POST /shares`、`POST /shares/:id/revoke`、`GET /audit` |

图片使用 `POST /api/media` 与受控的 `GET /api/media/:id`。CSV/XLSX 导入使用 `POST /api/import?preview=1` 预览、`POST /api/import` 提交；CSV 导出使用 `GET /api/export?kind=...`。公开分享页面为 `/share/:token`，账单还须输入访问码。

盘点扫码返回 `SEEN`、`RECHECK`、`MOVED_OUT`、`EXTRA`、`WRONG_LOCATION` 或 `UNREGISTERED`。快照外多货、错位货和未登记货号保存为待复核差异；复核人通过 `/stocktake-findings/:id/resolve` 提交 `disposition`（`MOVE_HERE` 或 `IGNORE`）与 `reason`。移入货位同时写入库存流水和盘点明细，未登记货号须先录货才能移入。盘点期间货品流转后，必须重新核对其货号，系统才更新该件的核对版本；未重新核对或仍有待复核差异时结束盘点会被拒绝。结束盘点需老板或获 `stockApprove` 权限的员工填写复核说明。

异常货复核由老板提交 `disposition`（`KEEP_HOLD`、`RESTORE` 或 `WRITE_OFF`）、`responsibility`、`reason`，可附已上传到该货品的 `imageId`。继续待处理保持不可售；修复放行改为品质正常；确认报损仍不可售。盘点未见货会生成异常记录。责任标记仅留痕，不自动生成扣款或退款。

### 请求例子

拿货：`POST /api/v1/loans`

```json
{"partnerId":"合作方ID","receiverName":"实际接收人","dueAt":"2026-12-31","goodIds":["货品ID"],"prices":{"货品ID":"1200.00"}}
```

收款：`POST /api/v1/receipts`

```json
{"partnerId":"合作方ID","kind":"SALES","amount":"300.00","method":"线下转账","allocations":[{"saleItemId":"销售明细ID","amount":"200.00"}]}
```

未指定核销的剩余100元保留为待分配销售款，不进入第二张销售单。押金须使用 `kind: "DEPOSIT"`，抵货款使用 `/receipts/:id/apply`。
