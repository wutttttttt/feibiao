# 微信小程序版

源码在 [`miniprogram`](../miniprogram) 目录。这是原生微信小程序，连接与网页相同的 `/api/v1`、货品图片和 PostgreSQL 账本，不另建一份数据。包含账号登录、首页指标、扫码新货入库、扫码查货、录货拍照与上传、预留、客户拿货、逐件归还与授权转交、成交、交付、收款、逐件核销、押金和预付款退款、销售退货、合作方档案、位置盘点、错位及多货差异处置、异常货照片与老板复核。库存与金额仍由服务端统一校验和提交。

新货入库：打开「货品」→「扫码入库」，扫描条码或二维码中的货号，填写名称、品类、货权和存放位置，点「保存货品」。成功后直接打开货品详情，可继续拍照；也可以「手工录货」，货号留空时系统自动生成。已存在的货号不能重复入库；外借货归还、销售退货须使用相应业务单据处理，不能新建同一件货。

生成的货号可在电脑网页端打印成条码标签，支持 Windows 已配对的 USB、蓝牙或 Wi-Fi 标签打印机。小程序目前没有跨品牌蓝牙直连打印入口；选定打印机型号后需要按设备协议适配，详见 [标签打印](./标签打印.md)。

## 本地开发

1. 先启动数据库和业务系统：`./scripts/start-db.ps1`、`./scripts/start-app.ps1`。
2. 用微信开发者工具导入 `E:\feibiao\miniprogram`。项目中的 `touristappid` 是**试用配置**，正式使用替换为实际 AppID。开发者工具项目设置中已关闭本地开发时的合法域名检查。
3. 在开发者工具模拟器里登录，服务器地址填 `http://127.0.0.1:3000`，可用 README 中的演示账号。这个地址仅适用于同一台电脑上的模拟器，**手机上的 127.0.0.1 指向手机自身**。

小程序继续使用系统账号和密码；暂未接入微信身份一键登录。小程序登录后取得有效期 12 小时的专用凭证，保存在微信本地存储中。退出登录会删除设备上的凭证；受保护的照片通过带凭证的请求下载。员工与客户范围权限由后端执行。接口中的金额字段虽然沿用 `...Cents` 名称，传输值已统一转换为十进制**元字符串**，小程序不会再除以 100。

## 真机与发布前配置

需要实际微信小程序 AppID，以及能由手机访问、证书有效的 HTTPS 业务域名。将同一个域名配置到微信小程序后台的 request、uploadFile、downloadFile 合法域名，并在登录页填该 HTTPS 地址。当前本机服务只监听 `127.0.0.1`，不能由手机或微信审核环境直接访问；须先完成服务器部署、域名与 HTTPS 配置。不能将 `127.0.0.1`、局域网 IP 或自签名证书当作正式发布方案。

正式使用前还应更换演示密码、分离正式数据库与图片目录、确认试用货权规则。小程序的发布审核、真机摄像头与上传下载验收需要 AppID 和可用域名，目前未执行。开发者工具尚未安装在这台机器上，因此小程序页面已完成源码与自动化接口检查，但尚未通过微信开发者工具编译或真机检查。

网页保留全部管理功能，包括导入导出、上游付款、调整单和员工权限；这些操作可在网页端继续办理。小程序第一版面向摊位高频操作，暂未在小程序里提供这些管理页面。
