# 一物一码与第三方标签打印机

每件新货在保存入库时取得一个唯一货号。留空时系统生成以 `FC` 开头的货号；也可手工填写已有标签货号。同一商家不能重复使用货号，货品与入库流水在同一事务保存。

电脑端录货成功后点击「打印刚入库的标签」，或在货品列表点击「标签」。标签页显示货名、Code 128 条码和货号，可选 70×40、60×40、50×30、40×30 mm 标签纸，然后点击「选择打印机并打印」。在系统打印窗口选择已安装的标签打印机。USB、蓝牙和 Wi-Fi 连接都由 Windows 打印机驱动负责；本系统不绑定某一品牌。选择与实际标签纸相同的尺寸、100% 缩放并关闭页眉页脚，先试打一张并用系统扫码查货核对。

蓝牙打印机应先在 Windows 中配对并安装厂商驱动，确认它出现在系统打印机列表。并非所有仅支持手机厂商 App 的蓝牙打印机都提供 Windows 驱动；购买前应确认这一点。当前没有已配对的实体打印机，因此纸张定位、条码可扫性和实际蓝牙输出尚未做硬件验收。

小程序可以自动生成货号并扫码录货，但尚未提供跨品牌的手机蓝牙直连打印。微信小程序具备蓝牙设备发现与 BLE 写入接口；各打印机接受的指令、字符集和标签定位方式仍由其型号或协议决定。若后续确定打印机型号，可按其 SDK 或指令协议增加小程序直连适配层。当前通用路径是电脑通过系统打印窗口打印。
