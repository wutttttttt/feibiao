# 备份与恢复

在 `E:\feibiao` 中执行 `./scripts/backup.ps1`。脚本会建立临时维护标记，业务写入接口返回“正在备份”，然后生成 `backups/<时间>/database.dump`、各业务表数量清单 `counts.json`，并复制 `storage` 图片目录，最后移除维护标记。备份时应避免手工修改图片目录。

执行 `./scripts/verify-restore.ps1 -BackupDirectory 'E:\feibiao\backups\<时间>'` 会创建新的 `feicui_restore_<时间>` 数据库，并将图片复制到 `.runtime/restore-verification`；它不会覆盖现有演示或正式库。新备份会逐表对比货品、单据、账目、盘点差异、异常货及审计等 28 张业务表的数量，并逐一核对图片文件 SHA-256。旧备份若没有 `counts.json`，仍核对货品与图片。恢复完成后，应抽样核对关键单据内容，再决定是否让业务系统使用该恢复库。

正式恢复应先停止应用，保留故障库和原图片，确认所选备份时间，在独立环境完成上述核验，再把 `.env` 的数据库地址和图片目录指向核验通过的恢复副本。恢复后重新启动并检查登录与抽样单据。不要把 `.env`、数据库备份或图片备份放到公开共享目录。
