# 需求与功能规划

## 使用者与主线

老板用手机快速录货、查货和看欠款；员工按授权交接、验货、成交及收款。合作方是一套档案，可同时具备客户、上游货主、供应商或代卖人身份，不要求直播间或平台订单。

主线为“收货入库 → 客户拿货 → 逐件归还或成交 → 登记收款并核销 → 寄售上游付款 → 对账”。拿货只改变持有和责任，不形成销售；销售只形成应收及寄售应付，不代表已经收付款。

## 页面

- 首页：在手、外借、成交、收款、欠款、货损与到期事项，直接跳转五项高频操作。
- 货品：录货、照片、搜索、条码标签、预留、位置调整、盘点与表格导入。
- 拿货单：多件交接、逐件参考价和应结价、部分归还、归还验货、成交及转交记录。
- 往来账：销售、交付、客户收款、多单核销、押金、期初余额、上游付款、退货和费用。
- 我的：合作方、员工权限、位置、分享、导出、试用规则与备份说明。

## 第一版边界

本地单摊位优先，可增加保险柜和库房位置。外部合作方不强制注册，通过受控对账链接查看。系统只记录实际线下收付款；分享链接不等于客户确认，也不自动预留货品。原生小程序已经覆盖摊位高频操作，发布和真机验收仍需 AppID、HTTPS 域名。平台订单、主播佣金、在线支付、RFID、AI 鉴定与完整会计总账不在第一版范围。
